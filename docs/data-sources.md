# Data sources and lineage

Every element in the model, and where it comes from. Generated by
`python scripts/data_sources.py` from `fpl/domain/lineage.py` — do not edit
by hand. `tests/test_lineage.py` checks the mapping against the real feeds,
so this cannot quietly drift from what the sources actually publish.

- **91 elements** across **15 entities**
- **56 read directly** from a source field
- **35 computed** by a named function
- **0 unsourceable** — every element in the model can be obtained
- Generated: 2026-08-09

See `docs/data-model.md` for the entity relationships and the grain of each.

## The feeds

| Key | Endpoint | Lifetime | Notes |
|---|---|---|---|
| `bootstrap.elements` | FPL API /bootstrap-static/ -> elements | live only | 573 players × 105 fields; season-to-date totals |
| `bootstrap.teams` | FPL API /bootstrap-static/ -> teams | live only | 20 clubs, including strength ratings |
| `bootstrap.element_types` | FPL API /bootstrap-static/ -> element_types | reference | 4 positions and their squad limits |
| `bootstrap.events` | FPL API /bootstrap-static/ -> events | live only | 38 gameweeks, deadlines |
| `fixtures` | FPL API /fixtures/ | whole season | 380 matches, published months ahead |
| `archive` | vaastav/Fantasy-Premier-League merged_gw.csv | permanent | third-party mirror; 43–51 columns by season |
| `odds` | The Odds API /v4/sports/soccer_epl/odds | live only | needs `ODDS_API_KEY`; 500 requests a month free |

**Live-only feeds are the ones that matter for persistence.** Anything
marked live only is published for *now* and never retrospectively, so the
daily capture in `fpl/store/snapshot.py` is the only record that will ever
exist of it.
